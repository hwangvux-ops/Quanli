MiSpace — Personal Hub

Ứng dụng quản lý cá nhân theo phong cách kết hợp Instagram, YouTube và Spotify.
Tính năng: trang chủ, thời khóa biểu tự nhập, quản lý thu chi, nhập CSV/JSON, thông báo nội bộ, hồ sơ và giao diện sáng/tối/auto. Có thêm trang Âm nhạc theo mood với trình phát giao diện mẫu (chưa phát nhạc thật).

Chạy thử: mở index.html hoặc triển khai toàn bộ thư mục lên GitHub Pages. Dữ liệu được lưu cục bộ trong trình duyệt.
